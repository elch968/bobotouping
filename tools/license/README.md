# 发码工具

给「电脑端」发授权码用。手机端不需要授权，这里只跟电脑端有关。

## 第一次使用

1. 双击 `初始化密钥.cmd` 生成一对密钥（只需做一次）。
2. 把 `.tools/license/private.pem` 复制一份到别的地方保存（U 盘、密码管理器都行）。
   这个文件丢了就再也发不出新授权码，只能重新生成密钥，而那会让所有老授权码失效。
3. 生成的 `desktop/src/main/license.pub` 要跟着代码提交，客户端靠它验签。

## 平时发码

1. 对方打开电脑端，界面上显示设备码，比如 `B7K2-M9QD-4XZP`。
2. 双击 `一键发码.cmd`，按提示填设备码、授权给谁、有效天数（留空即永久）。
3. 生成的授权码会自动复制到剪贴板，直接微信发给对方。
4. 对方在电脑端把授权码粘贴进输入框，点「激活」即可。

也可以直接用命令行：

```
node tools/license/issue.js B7K2M9QD4XZP "张三" 365
```

第三个参数是天数，填 0 或不填表示永久有效。

## 注意事项

- 授权码绑的是那台电脑。对方换电脑、换主板之后要重新发一份。
- 私钥 `private.pem` 绝对不能提交进仓库、不能发给任何人。
  `.tools/` 已经在 `.gitignore` 里，正常情况下不会被提交。
- 每次发码都会往 `.tools/license/issued.log` 记一笔，方便回头查这个码发给谁了。
- 授权码里带对方的名字，激活后对方电脑上会显示「授权给：张三」，
  软件被转发出去时一眼就能看出是从谁那里流出去的。
